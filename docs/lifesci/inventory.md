# Scientific evaluation inventory

We identified 63 candidates containing an LLM or agent evaluation, a documented public scored release, and creator-reported results from a 302-entry source inventory. There are 59 configured entries, three partial implementations, and one source-access case.

The October 23 review inspected the source and implemented scope of all 63 candidates. The scope column identifies the actual implementation; several rows cover a subset of the creator’s suite. Population counts describe released inputs and are separate from completed validation tasks. Runtime qualification, model execution, independent review, and final acceptance remain explicit in [inventory.json](inventory.json).

Existing Gym adapters were available for GenoTEX, PromptBio, and ProteinLMBench; upstream Harbor adapters were available for CompChemBench, NatureBench, and MDArena. See the [execution plan](PLAN.md) for the uniform acceptance criteria.
