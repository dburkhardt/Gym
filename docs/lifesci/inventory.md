# Scientific evaluation inventory

We identified 63 entries containing an LLM or agent evaluation, a documented public scored release, and creator-reported results. The source inventory contained 302 entries. Subsequent implementation exposed access, dependency, execution, and scoring limitations.

The initial review identified existing Gym adapters for GenoTEX, PromptBio, and ProteinLMBench, and upstream Harbor adapters for CompChemBench, NatureBench, and MDArena. Other entries needed additional implementation or source preparation.

The table below preserves observations from the earlier work. All 63 will undergo the same acceptance process in the [execution plan](PLAN.md). A recorded scoring check does not imply that every acceptance step has passed. The machine-readable project status is [inventory.json](inventory.json); accepted task counts will be populated only after the fixed sample is reconciled.
