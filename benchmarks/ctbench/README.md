Clone the source repository and configure `ctbench.resources_servers.ctbench.creator_root` with its absolute path and `judge_model_server: {type: responses_api_models, name: judge_model}`. Dependencies are the normal Gym runtime; upstream code is AST-isolated to its five deterministic functions, without importing OpenAI or credentials. `gym eval run --benchmark ctbench` is the intended native entry point; full native configuration and HTTP tests plus live five-item rollouts have been exercised.

Raw creator behavior includes division by zero when no candidate features are extracted. This is retained as a grading error, not silently assigned a score. An additional integrity guard rejects judge outputs that hallucinate, duplicate, or omit input features. The creator scorer itself merely counts returned list lengths. This guard is a documented deviation; retain judge receipts for later raw replay. A nonempty incorrect candidate gives F1 0; exact matching lists give F1 1. Empty output remains a scorer failure.
