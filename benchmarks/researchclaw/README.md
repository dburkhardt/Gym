It does not claim coverage of all40 mixed-domain tasks. The generated manifest lists every remaining task explicitly; eligibility of those remaining tasks requires individual review.

Neuroscience_000's machine_results_reference.csv is deliberately retained: the creator explicitly supplies this as public contextual input. Public reference material is therefore not synonymous with hidden grading data.

The two tasks are a CPU/no-network campaign variant, bounded2CPU/4GiB/7200s; this is not the paper's complete agent protocol. The current files are staging, not a launch-ready integration. No inference has run.
