## Maintained scientific-verifier path (offline validated; live gate pending)

`gym eval prepare --benchmark researchclaw` and `gym eval plan --benchmark researchclaw --out PLAN.json` now use `config.yaml`. This selects `ResearchClawVerifier`, not the default artifact-capture verifier. Set `CAMPAIGN_SAMPLE_JSONL` to the preserved two-row Harbor input and `CAMPAIGN_SAMPLE_SHA256` to its recorded digest. Preparation refuses a different task set or changed empty-input Harbor protocol and publishes those bytes atomically. The older `campaign.yaml` alone remains an artifact-capture configuration and must not be reported as scientific benchmark success.

The scientific verifier requires `provider_dispatch_guard=true` and the corresponding capture configuration, plus `RESEARCHCLAW_SOURCE` (the pinned creator checkout), `RESEARCHCLAW_FROZEN_MANIFEST`, its `RESEARCHCLAW_FROZEN_MANIFEST_SHA256`, and `RESEARCHCLAW_CONTROLLER_PYTHON`. The dedicated controller environment must include this Gym fork and `benchmarks/researchclaw/requirements.txt`. Existing `POLICY_*` and `SCIENTIFIC_HARBOR_*` settings still apply. These are configuration requirements, not permission to change sample size or use another model.

Source is pinned to `23e0a589321e449727c34aef107c49adcf977457`; the controller verifies hashes of the creator scorer/config/utils/package initializer and requires structai 0.1.23. Frozen manifest hashes bind instructions and hidden target-study files. The verifier downloads submitted workspace into its private verifier directory, rejects links and modified instructions, and never copies creator references into the solver. It persists a fresh verifier lineage before inference. A preexisting verifier directory is refused; automatic cross-trial resume is not claimed.

`guarded_score.py` invokes the creator `score_workspace` and real structai prompt/image construction and parser. Creator weights, rounding, 500-token budget, temperature 0 and max_try2 remain intact. Each criterion gets a separate transport bound to its original checklist index; a parser retry has a distinct explicit try index. Identical criterion text is not used as identity. A pending/failed transport poisons that criterion, so the creator's broad exception handler cannot silently resend after an uncertain outcome. All calls go through Gym's shared aiohttp transport with retries disabled and stable capture headers. Scientific reward is the native weighted checklist score divided by 100; malformed, missing or unresolved judges produce verifier failure, not 0. A valid native 0 remains valid.

Offline controls exercise the actual pinned scorer and real parser with fake responses, preserving a 1:3 weighted 0/100 score of 75, distinct parse-retry identities and fail-closed ambiguous transport. Native config/preparation and Harbor verifier contracts also pass. Full container download, reference-denial and live all-role capture/cleanup acceptance remain required before this path is considered accepted.
