# BLADE native Gym integration

Source pin: `6118fa8d5007b91aa8c91c518182db82446a4547`. Preparation validates 186 released source/data files and preserves the existing biological selections crofoot, panda_nuts and amtl. Public CSV/info and native code are staged separately from annotations/MCQ references. Atomic restaging preserves task identities and rejects contaminated solver contexts.

`config.yaml` uses native Harbor custom agent/verifier hooks. The solver delegates unchanged to `RunLLMMultiRun(use_agent=True, use_data_desc=True, num_runs=1, use_code_cache=False)` and native ten-turn behavior. The scorer separately calls `run_eval_on_analyses`. Both use the historical Python3.11/Torch2.5.1 CPU image digest, with2CPU/4GiB solver and1CPU/2GiB scorer limits plus3600s per-phase budgets. A small separate Harbor environment stores `/workspace/solver` for native saved-output regrading. Full native metric artifacts remain available; ten native hit-rate/average-coverage metrics are returned as a vector, not invented scalar accuracy. Non-success native statuses remain explicit failures with preserved artifacts.

Every LLM role, including repair and matching, uses exact Nemotron3.5SuperVL. The Python3.11 runner talks HTTP over a task-owned Unix socket to the Python3.13 Gym controller. Both scientific containers have Docker `network=none`; they cannot reach host loopback or other network services. The socket bridge accepts only one route, bearer token, exact model, lineage and configuration digest; it caps request bodies, disables redirects/resends, and forwards only to that task's fixed guarded model endpoint. The token is not forwarded upstream or included in lifecycle receipts. Solver mounts contain no references, inference key, host Docker socket or unrelated host workspace. Scorer references are mounted read-only only during its separate phase.

Native calls persist request intent and response before returning, and an ambiguous/failed call poisons the phase. Existing phase directories are refused rather than silently restarting. This is fail-closed recovery, not arbitrary native solver continuation. Creator OpenAI client transport is replaced; prompts, scoring, model settings, transformation code and parsing stay native. Explicit protocol variant: hidden transport retries are disabled, and incomplete/wrong-model responses fail qualification rather than being silently repaired.

Prepare with `BLADE_SOURCE=/path/to/pinned/source python -m benchmarks.blade.prepare`, then compose `benchmarks/blade/config.yaml` with the guarded policy model configuration. The pinned image must already be available; it is not a portable dependency lock. Work from the Gym checkout root so staged paths resolve.

Validation so far is offline: actual pinned-source staging/isolation, Harbor Task/config parsing, imported native hook interfaces, real Unix-socket HTTP roundtrip and scope rejection, cancellation settlement, and saved native metric-vector inspection. **No Docker runtime acceptance or live inference on these new hooks yet.** Before activation, verify the pinned image/import paths, actual network and reference isolation, native positive/negative scorer controls, preserved solver artifact replay, scientific failure classifications and cleanup on the existing approved worker.
