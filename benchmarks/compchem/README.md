# CompChemBench

This adapter stages the 43 creator Harbor tasks from commit `772d3f3e1a93b875f49ddb692e6dfc3db1d3593d` through Gym's existing Harbor agent. It does not introduce another harness. Preparation requires a pinned source checkout and the previously reviewed campaign overlay bundle; it fails closed if the manifest, source files or prepared files differ. The bundle is identified by SHA256 `387ff4e1750b432906d555576a55a7d31dd859a2efbf47c018967d1ea834fa5a`.

Set `COMPCHEM_SOURCE_DIR` to the creator checkout and `COMPCHEM_PREPARED_DIR` to the overlay bundle containing `manifest.json` and `tasks/`. Run `gym eval plan --config benchmarks/compchem/config.yaml --out compchem-plan.json`. `COMPCHEM_LIMIT` selects the preserved frozen prefix: 5 (default), 20, or all 43. Every file is checksum-validated before publication; the shared `stage_file` helper handles interrupted copies. `data/provenance.json` binds task files and dataset hashes. Compare its dataset hash before using a receipt after interruption.

The preserved overlay normalizes resource fields, adds tmux/asciinema to task images, and appends artifact capture after the native verifier. Scientific instructions, assets and `verify.py` files remain byte-identical to the creator source. Native task solver/verifier time limits remain intact. The JSON Terminus2NemoGym agent uses Docker and the configured `policy_model`. Live campaign use must compose the authorized Nemotron policy server and capture/dispatch guard config; all LLM roles must use `nvidia/nvidia/nemotron-3.5-super-vl`. These tasks use native programmatic tests, not a new LLM judge.

Preparation and planning do not establish live readiness. Container builds, guarded agent calls, cleanup and saved-result regrading still require runtime acceptance for this maintained path. The historical 20-task campaign had 17 raw passes but is not 17 scientifically certified successes: controlled replays exposed LAMMPS neighbor-schedule sensitivity, CP2K SZV electrostatics sensitivity, and a QE case changing physical atomic positions. Preserve those qualifications when reporting native verifier rewards. No new inference is part of preparation.
