The 200 human abstract pairs use original creator extraction, original RandomState(42) option swaps, and the creator generic GPT2 prose prompt. This is an explicit **Nemotron chat-template-conditioned likelihood variant**. It retains the creator whole-prompt mean negative log likelihood decision, counting ties incorrect. The API scores the full server-rendered chat prompt, including wrapper tokens; it is not identical to a local forward pass on the raw creator template. Never report it as canonical cross-model reproduction. There are no forced-choice QA requests. Each case makes two guarded requests through its configured Gym model server, using exact Nemotron3.5SuperVL and prompt_logprobs0. One generated token is discarded; prompt token likelihoods determine reward. Raw requests and likelihood receipts are retained in the Gym response. Gold target lives only in verifier metadata.

Run prepare.py with --experiments, --testcases and --out; source pins are checked. Native config registers agent, stateless resource verifier and legacy environment.
