# Headless image observations (opt-in harness variant)

`Terminus2ImagesNemoGym` retains the pinned Terminus terminal loop and adds a sole-command `gym_view_image <relative-path>` operation. The frozen task instruction remains an exact prefix; an explicit harness instruction explains the tool. Use `configs/harbor_agent_images.yaml` with a reviewed `NEMO_GYM_IMAGE_ROOT` beneath `/workspace`, an available container Python interpreter, authoritative provider dispatch guard, and Pillow12.3.0 (repository lock) installed in the agent runtime. Defaults remain text-only. A model name alone does not establish vision support.

The reader opens every directory component without following symlinks and reads a bounded regular file descriptor. PNG/JPEG byte and pixel limits apply. Exact image bytes and SHA256 metadata are retained under the agent's `image-observations` artifact directory. Only a registered token at its registered user turn is projected to image_url content; all original text remains, including native completion/warning wrappers. Historical images are re-projected unchanged before request hashing. Model mistakes (mixed commands, unsafe/missing relative paths, invalid or oversized images) return bounded text tool errors, consuming the normal turn/time budget and allowing correction. A missing configured root/reader is refused before model dispatch. Registry tampering, identity failures, artifact I/O failures and transport errors remain terminal. No implicit restoration is supported: a preexisting registry and a reused agent run are refused. Images are not inferred from arbitrary terminal text.

The standalone local tests exercise the real guarded Gym Chat Completions handler, capture middleware and a loopback provider for three requests, including historical image retention and an accepted timeout without resend. The pinned Terminus.run/Chat/agent loop is exercised for warning-wrapped observations and completion confirmation. Reader and registry controls include real filesystem checks. These tests do not claim an end-to-end scientific workflow, remote container acceptance, actual provider vision support or canonical harness parity. A bounded existing-image transport control remains a separate admission step; no rebuild is required.
